# Демо для проверяющих акселератора: план

> Ветка `claude/demo-subdomain`, worktree `.claude/worktrees/demo-subdomain`.
> Владелец отказался от вопросов («да продолжай всё»), решения ниже — наши.
> В продакшен уходит только после его явного «да», как обычно: коммит в `main` и пуш.

## Зачем

Проверяющий акселератора открывает `demo.timely-plan.study` и за минуту понимает
суть Timely. Регистрации нет: он сразу внутри заполненного аккаунта ученицы, и тур
со слизнем подсвечивает главное. Английский нужен только на лендинге и в карточках
тура; само приложение остаётся на русском (решение владельца).

Суть, которую должен унести проверяющий (наше решение): Timely превращает школьный
хаос в один понятный следующий шаг, а тьютор помогает, но не решает за ученика.

## Архитектура

Тот же код, ещё две выкладки из `main`:

- **Railway**: сервис `timely-demo` из того же `Dockerfile` и своя Postgres.
  Переменные: `DEMO_MODE=true`, свой `SECRET_KEY`, свой `TIMELY_API_JWT_SECRET`,
  `DATABASE_URL` своей базы, `OPENROUTER_API_KEY` (лучше отдельный ключ с потолком
  трат), `AI_FREE_TOKEN_5H_LIMIT=40000`, `AI_FREE_TOKEN_WEEKLY_LIMIT=80000`,
  `DEMO_DAILY_TOKEN_BUDGET=1500000`, `CORS_ALLOWED_ORIGINS=https://demo.timely-plan.study`.
- **Vercel**: проект `timely-demo` из того же репозитория, домен `demo.timely-plan.study`.
  Переменные: `NEXT_PUBLIC_DEMO_MODE=true`, `DEMO_MODE=true`,
  `NEXT_PUBLIC_API_URL=<адрес timely-demo>`, тот же `TIMELY_API_JWT_SECRET`, что у
  демо-бэкенда, свой `NEXTAUTH_SECRET`, `NEXTAUTH_URL=https://demo.timely-plan.study`,
  `TIMELY_APP_HOST=demo.timely-plan.study`, `TIMELY_APP_ORIGIN=https://demo.timely-plan.study`,
  `TIMELY_MARKETING_HOST=timely-plan.study` (иначе `/en` на демо уведёт на запасной
  `timelyplan.me`). Флаги демо — только оба вместе и только здесь.
- **DNS**: CNAME `demo` на Vercel.

Почему отдельная база: контесты и рейтинг общие для всех учеников. Выдуманные
одноклассники и контесты не должны попасть к настоящим ученикам, а данные настоящих
(несовершеннолетних) учеников не должны попасть к проверяющим (CLAUDE.md §17.3).

## Вход без пароля

- `DEMO_MODE=true` на Next включает единственного провайдера NextAuth `demo`: он без
  полей и выдаёт новую личность `visitor-<uuid>@demo.timely-plan.study`, имя «Алия».
  Google и пароль в демо выключены. В продакшене (`DEMO_MODE` не задан) провайдера нет.
- Middleware в демо отправляет без сессии на `/demo`, а не на `/auth/signin`;
  `/auth/*` и `/register` в демо тоже ведут на `/demo`.
- `/demo` (публичная страница): `signIn("demo")`, затем `POST /api/demo/start/` с
  `{"tz": "<IANA зона браузера>"}`, затем переход на `/?tour=1`. Пока идёт — слизень и
  «Готовим демо…» / «Setting up the demo…».
- Вернувшийся посетитель с живой сессией: баннер демо один раз за загрузку вызывает
  `start` ещё раз. Если данные пересобраны (новый день), страница перезагружается.

## Сервер: приложение `demo` (backend/demo)

Без моделей и миграций, ставится всегда. Всё работает только при `settings.DEMO_MODE`,
иначе эндпоинт отвечает 404 и middleware ничего не делает.

- `POST /api/demo/start/` → `{"ok": true, "seeded": bool}`.
  - Личность из подписанного токена (`request.user_email`), только по шаблону
    `^visitor-[0-9a-f-]{8,64}@demo\.timely-plan\.study$`, иначе 403.
  - Мир (одноклассники, учитель, контесты) создаётся один раз, идемпотентно.
  - Данные посетителя пересобираются, если их нет или они собраны в прошлый день по
    его зоне. Иначе ничего не делает.
  - Не больше 20 новых посетителей в час с одного IP (кэш Django), иначе 429.
  - Попутно удаляет посетителей старше 14 дней (порциями).
- Глобальный дневной бюджет ИИ: если за 24 часа все пользователи демо потратили
  больше `DEMO_DAILY_TOKEN_BUDGET`, ИИ-запросы получают 429 с понятным текстом. Те же
  пути, что считает `ai_engine/middleware.py`.
- Команды: `demo_seed_world`, `demo_prune`.
- Не трогать `ai_engine/usage.py` и уже существующие куски `settings.py` сверх
  пары строк: рядом идёт план «Книги на Railway», он их меняет.

## Тур (фронтенд)

`src/components/demo/`, стили `src/styles/timely/page-demo.css` через `index.css`.
Монтируется в layout дашборда только при `NEXT_PUBLIC_DEMO_MODE === "true"` через
`next/dynamic`. Цели помечены `data-tour="…"`.

Подсветка: затемнение вокруг цели, под целью стеклянная карточка (над целью, если
внизу нет места), на телефоне карточка внизу экрана. В карточке маленький слизень,
«3 / 7», «Назад», «Дальше», крестик, переключатель EN/RU. Язык по браузеру (ru, kk →
русский, иначе английский). Esc закрывает, стрелки листают. Тур можно запустить снова
из баннера демо.

Остановки:

0. Приветствие (по центру). EN «Hi, I'm the Timely slime» / RU «Привет, я слизень Timely».
1. «Сейчас», текущий блок: один следующий шаг с таймером и понятным «готово».
2. «Неделя»: уроки, домашка и учёба в одном календаре; ИИ показывает, что сдвинется.
3. Тьютор, чат про тригонометрию: подсказки по шагу, проверка, похожая задача;
   «спроси сам, ответит по-настоящему».
4. Слабые темы: интервальное повторение коротким вопросом.
5. Цели: каждый блок учёбы привязан к цели.
6. Контесты и рейтинг: навык, а не время в приложении.
7. Строка вопроса внизу: есть на каждой странице и готовит изменения с «Применить».

Плашка «Демо-аккаунт · Тур» стоит в левой панели над профилем: там она не закрывает
ни одну страницу. На телефоне панели нет, там только кнопка «Тур» внизу слева над
вкладками (в чате её нет: там поле ввода). Цели тура — классы самих страниц
(`li.step.is-now`, `.cal-wrap`, `.log`, `.rv`, `.plq-hero-wrap`, `.q-pill`), без
`data-tour`: если вёрстка поменяется, карточка просто встанет по центру.

## Лендинг

Ссылка «Демо» в шапке и кнопка «Посмотреть демо» / «Try the demo» внизу появляются,
только когда задан `NEXT_PUBLIC_DEMO_URL` (на продакшен-проекте Vercel —
`https://demo.timely-plan.study`, после запуска демо). Пока демо нет, ссылок нет.

## Проверка

- Бэкенд: тесты приложения `demo` (мир идемпотентен, посетитель собирается, 404 без
  `DEMO_MODE`, 401 без токена, 403 чужой адрес, повторный вызов в тот же день ничего
  не меняет, удаление старых посетителей, дневной бюджет) и весь набор на копии
  backend/ без `.env` (см. память о тестовом стенде).
- Стенд: бэкенд с `DEMO_MODE=true` на SQLite (порт 8140) и фейковой моделью (8240),
  Next с `NEXT_PUBLIC_DEMO_MODE=true`/`DEMO_MODE=true` на `http://demo.localhost:3340`.
  Не на 127.0.0.1: другой локальный Next с другим `NEXTAUTH_SECRET` сбрасывает куку,
  потому что куки не различают порты. Пройти вход и тур реальными кликами, скриншоты
  компьютера, 735 px и телефона, продакшен-сборка.
- Продакшен-сборка без `DEMO_MODE`: провайдера `demo` и тура нет.
